# hypabolic-trajectory

Native Rust implementation of the language-neutral Trajectory contracts.

ML3 provides exact byte-oriented Pi normalization, typed errors and
diagnostics, deterministic canonical identity, the three identity-bearing
wire projections, and synchronous explicit-root Pi listing. The crate uses
Rust 2024, supports Rust 1.85 and newer, forbids unsafe code, and has no
SQLite or OpenTelemetry dependency.

See the repository's
[Rust workspace documentation](https://github.com/Hypabolic/Trajectory/tree/main/rust)
and [shared contracts](https://github.com/Hypabolic/Trajectory/tree/main/contracts)
for behavior and validation commands.
