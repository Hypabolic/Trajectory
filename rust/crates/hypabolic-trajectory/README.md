# hypabolic-trajectory

Native Rust implementation of the language-neutral Trajectory contracts.

ML7 provides exact byte-oriented Pi, Claude Code, and Codex normalization,
typed errors and diagnostics, deterministic canonical identity, all six shared
wire projections, retained source execution metadata, incremental writer
surfaces, and synchronous explicit-root listing. The crate uses Rust 2024,
supports Rust 1.85 and newer, forbids unsafe code, and has no SQLite or
OpenTelemetry dependency.

See the repository's
[Rust workspace documentation](https://github.com/Hypabolic/Trajectory/tree/main/rust)
and [shared contracts](https://github.com/Hypabolic/Trajectory/tree/main/contracts)
for behavior and validation commands.
